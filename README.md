# 🖥️ Dependability and Performability Modelling for Supporting MEC-SDN Infrastructure Planning
 
> *A one-line description of what this project does and why it matters.*
> This doctoral research evaluates an edge computing infrastructure based on software-defined networks for real-time processing, storage, and forwarding. It comprises an infrastructure MEC based on SDN to enable on-demand provisioning of network resources such as high throughput and low to medium latency, for ensuring achievement related to the fifth generation (5G) mobile and wireless technology, known as eMBB, mMTC, and URLCC services.
