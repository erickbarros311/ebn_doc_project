# 🖥️ Dependability and Performability Modelling for Supporting MEC-SDN Infrastructure Planning
 
> *This doctoral research evaluates a Multi-access Edge Computing (MEC) infrastructure based on Software-defined Networks (SDN) for real-time processing, storage, and forwarding. It comprises an programmable ecosystem to enable on-demand provisioning of network resources such as high throughput and low to medium latency, for ensuring achievement related to the fifth generation (5G) mobile and wireless technology, known as eMBB, mMTC, and URLCC services.*
